# Pinxai ウィジェット相談室

[配布ページ](https://munn-nnuw.github.io/pinxai-widget-workshop/)を開き、「最新版をコピー」から新しいAIチャットに開始プロンプトを貼り付けてください。

## 配布版を更新する

1. `start-prompt.txt` を新しい開始プロンプトの全文に置き換えます。1行目は `Pinxai ウィジェット相談室 v1.1` と同じ形式で、版番号を更新します。
2. `index.html` の最新版と更新日を更新し、更新履歴の先頭に新しい項目を追加します。従来の項目は残します。
3. 両ファイルを同じコミットで更新します。公開後に配布ページの表示と、コピー結果の版を確認します。

配布ページのURLは更新後も共通です。公開した本文の旧版は `start-prompt.txt` のコミット履歴から確認できます。

## サンプル集を更新する

公開資料と初期の作例原文は [widget-reference](https://github.com/munn-nnuw/widget-reference) にあります。追加の作例「複数の操作をまとめて入力する」の原稿はこのリポジトリの `samples.html` に掲載しています。サンプルを更新するときは、紹介と試し方、原文の冒頭から設置直前までを入れた `sample-source-notes`、設置から再現・確認までの各 `data-section` を照合します。原文を掲載する際は `<`、`>`、`&` をHTML用にエスケープします。相談チャット用のコピーは、依頼文とこれらの原文をつなげたものです。

既に共有されたURLが使えるよう、掲載済みのサンプルの `id` は維持します。公開後にトップから一覧への遷移、相談チャット用の全文コピーと、自分で組み込む場合の欄別コピーを確認します。

## 寄稿ガイド

`first-widget.html` はRinさん寄稿の「はじめてのウィジェット」です。図解と作例画像を含み、図はファイル内に入っています。公開後はトップからガイドを開き、目次と、相談室・サンプル集へ進むリンクを確認します。
