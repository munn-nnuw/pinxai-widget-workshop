# Pinxai ウィジェット相談室

[配布ページ](https://munn-nnuw.github.io/pinxai-widget-workshop/)を開き、「最新版をコピー」から新しいAIチャットに開始プロンプトを貼り付けてください。

## 配布版を更新する

1. `start-prompt.txt` を新しい開始プロンプトの全文に置き換えます。1行目は `Pinxai ウィジェット相談室 v1.0` と同じ形式で、版番号を更新します。
2. `index.html` の最新版と更新日を更新し、更新履歴の先頭に新しい項目を追加します。従来の項目は残します。
3. 両ファイルを同じコミットで更新します。公開後に配布ページの表示と、コピー結果の版を確認します。

配布ページのURLは更新後も共通です。公開した本文の旧版は `start-prompt.txt` のコミット履歴から確認できます。

## サンプル集を更新する

公開原文は [widget-reference](https://github.com/munn-nnuw/widget-reference) にあります。`samples.html` に用途別の紹介と試し方、原文へのリンクを載せます。既に共有されたサンプルのリンクを保つため、掲載済みの `details` の `id` は維持します。トップの代表例を変更する場合は `index.html` のリンク先も確認します。
